# Photon Frame · 光子水印

一个完全在浏览器本地运行的照片参数水印工具。它会从相机 JPEG 中自动读取 EXIF，把相机厂商、机型、镜头、光圈、快门、ISO、焦距和拍摄时间排版到水印或相框中。

## 已实现

- 经典白色铭牌、夜黑铭牌、画廊相框、渐变叠印、胶片索引 5 种样式
- 17 个相机与手机厂商 Logo；胶片索引与其他样式共用同一套 Logo 渲染，并可从 EXIF 厂商或机型自动识别
- 手机识别覆盖 Apple / iPhone、Huawei / 华为、HONOR / 荣耀、Xiaomi / Redmi / POCO、OPPO / OnePlus、vivo；识别不到时仍可手动选择或填写
- 厂商可选择，机型、镜头、光圈、快门、ISO、焦距和日期可逐张手动覆盖，并可恢复 EXIF 自动识别值
- 相机型号、镜头、光圈、快门、ISO、焦距、日期和签名均可独立开关
- 独立胶片信息模式：支持 Kodak、Lucky、Fujifilm 胶卷 Logo、胶卷名称、自定义冲洗店，以及 Noritsu / Fujifilm 扫描仪 Logo 与型号；胶片信息也可逐项开关，并继续沿用当前预设的白底、暗色、画廊或渐变叠印视觉
- 所有预设和胶片模式均支持类似 PPT 的画布编辑：点击元素选中、拖动移动、拖拽四角手柄缩放、双击文字编辑；每个预设的布局单独保存
- 普通模式与胶片模式分别保存铭牌高度、参数开关和元素位置；胶片铭牌默认高度为 12%，默认参数为 OLYMPUS / OM-1 / 50mm/1.8 / KODAK EKTAR100 ISO100 / NORITSU HS-1800 / 我的冲洗店，并默认隐藏日期、快门、光圈和独立焦距参数
- 正常模式铭牌默认高度同样为 12%，相机型号与镜头位于第一行，光圈、快门、ISO 与焦距位于第二行且使用一致字号
- 调整正常模式铭牌高度只改变元素的纵向位置和留白，Logo 与字体保持原 16.12% 高度时的视觉尺寸
- 调整胶片铭牌高度只改变两行元素的相对位置，Logo 与字体的视觉尺寸保持不变
- 新增“柯达胶片”与“富士胶片”主题：铭牌保持纯白，照片与铭牌之间使用约 28.7% / 71.3% 的双色分段条；柯达采用官方 Yellow `#FFB700` 与 Red `#ED0000`，富士采用 Advanced Green `#01916D` 与高对比浅绿 `#99D3C5`；主题内容会整体下移，与色带保持清晰间距，两种主题均适用于普通与胶片模式
- 多照片导入、切换与 ZIP 批量导出
- PNG 无损导出，或最高质量 JPEG 导出
- 原照片像素不缩放；边框样式只扩展画布
- 全程本地处理，照片不会上传服务器
- 响应式桌面与移动端界面

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。测试照片位于 `tmp/`，不会被网页自动上传或读取，需要手动选择。

## 构建

```bash
# GitHub Pages 纯静态构建，输出到 gh-pages/
npm run build

# 可选：构建 Sites / Cloudflare Worker 版本
npm run build:sites
```

## 发布到 GitHub Pages

仓库已经包含 `.github/workflows/pages.yml`。将代码推送到 `main` 后，在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**，之后每次推送都会自动构建并发布。

如果绑定自己的域名，请同时在 GitHub Pages 设置中配置域名；不要只添加 `CNAME` 文件。

## 图片与隐私说明

浏览器 Canvas 导出的 PNG 是无损编码，照片区域保持原始宽高；经典、暗色、画廊和胶片样式会为边框扩展最终画布尺寸，渐变叠印保持与原图相同的最终尺寸。Canvas 导出不会保留原文件中的 EXIF 数据，但水印里会展示解析到的拍摄参数。

## 厂商 Logo 与商标

内置 Logo 均直接取自对应厂商官网，没有重新描画。来源和公开部署前的商标注意事项见 [`TRADEMARKS.md`](TRADEMARKS.md)。Logo 仅用于标识用户所选相机厂商，所有商标权归各厂商所有；公开或商业部署前请自行确认授权要求。
